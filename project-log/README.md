# Project Log

This directory contains Context Baggage's historical development record.

```text
docs/
    normative/current documentation

project-log/
    chronological/historical development record
```

Current product truth lives in `docs/`. The project log records how and why the project reached that state.

## `sessions/`

Meaningful development sessions.

Use:

```text
sessions/YYYY-MM-DD/session-NNN-description.md
```

## `decisions/`

Architecture Decision Records. ADRs capture durable technical and product decisions, including context, decision, consequences, and alternatives.

## `milestones/`

Execution progress for releases.

## `research/`

External research, comparisons, experiments, and findings. Research is historical evidence, not automatically normative product requirements.

## `ideas/`

Future concepts deliberately excluded from current scope.

`ideas/` is a scope-creep quarantine. Recording an idea there does not approve it for implementation.
