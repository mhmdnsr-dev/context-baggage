# Session 002: Name and CLI

Date: 2026-08-24

## Naming Evolution

Initial candidate:

```text
AgentContinuum
```

Final name:

```text
Context Baggage
```

Chosen CLI:

```text
ctx-bag
```

Alternative considered:

```text
ctx-bg
```

## Rationale

Reasons for choosing `ctx-bag`:

- directly maps to Baggage;
- more memorable;
- avoids ambiguity with "background";
- supports good developer branding.

## Brand Direction

```text
Context Baggage
Carry your agent context wherever you work.
```

CLI commands should remain professional rather than turning every operation into baggage-themed jokes.
